## Gaps
- The exact percentage or token threshold at which auto-compact fires: the docs point to a per-model "Default auto-compact thresholds" section in model-config, which I did not open. Third-party figures (about 83.5%, or 64-75%) disagree and are not official, so I did not record them.
- The docs pages I opened do not define "token" in plain words, so a beginner definition of token has no official-doc quote.
- The docs pages I opened do not define "disk", "model" or "code snippet" for beginners; plain-language glosses of those would be the writer's own wording, not sourced.
- The word "short" for the summary is not in the docs; C12 supports only "to fit the context window". Review issue 5 (final.md, status.md) is for the writer, not research.
